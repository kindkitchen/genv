# genv-js extracted to its own repo + submodule

The engine is now a standalone repository, https://github.com/kindkitchen/genv-js
(public), added to the parent repo as a git submodule at `engine/` via its remote
HTTPS URL (`.gitmodules`).

- `deno.json` + `deno.lock` moved from the parent root into `engine/`; exports
  adjusted to `./mod.ts`, tasks to `deno test` / `deno run mod.ts`. The genv-js
  repo is now a self-contained, JSR-publishable package.
- Added `engine/README.md` (library + CLI usage).
- Parent: committed everything except engine first, then the submodule pointer.

Consumers (action-js-parity, spa-site) reference genv-js via the submodule path
or `jsr:@kindkitchen/genv`. JSR publish is still pending.
