# 8-bit / NES pixel visual pass; browser-verified

Restyled site/index.html to an 8-bit / NES-era pixel theme per the Dribbble
"Build A Map" direction ([[006.log]]), confirmed by the user's spoiler
(super-mario / pixel). Markup + JS unchanged — `<style>` rewrite only.

- Fonts: Press Start 2P (headings/labels) + VT323 (body/output) from Google Fonts
  CDN — a new external dep alongside esm.sh, consistent with the no-build CDN
  approach.
- Chunky 3-4px black outlines, hard offset shadows (`Nx Nx 0`), sharp edges, NES
  sky-blue bg with a faint pixel grid; coin-gold / brick-red / pipe-green palette;
  CRT-navy output screen with green text; step tiles as gold "?" blocks with coin
  numbers (greyed when skipped); pressable copy button. Light + dark variants.

Verified via headless-chromium screenshot of the served page: renders correctly
(dark variant captured) and the playground runs live — engine loaded from esm.sh,
resolved .env + per-step tiles populated, skipped step greyed. This also clears
the earlier "DOM wiring not yet confirmed in a browser" gap from [[009.summary]].
