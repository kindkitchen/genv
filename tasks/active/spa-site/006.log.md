# Dep rewire + visual style direction

Architectural pivot (see js-engine task): genv-js becomes the source of truth for
the merge pipeline. The playground no longer ports the merge logic itself — it
reuses genv-js. Added `js-engine` to `relates`; the playground now depends on
genv-js existing first. The [[002.analysis]] spec moves upstream into js-engine
(this task keeps it for reference but the canonical implementation is genv-js).

Visual style direction chosen: Dribbble "Build A Map" game UI/UX —
https://dribbble.com/shots/24895606-Build-A-Map-game-UI-UX-design — a playful,
game-like UI/UX to make the playground feel like something to try and explore.
