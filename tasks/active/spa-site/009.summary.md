# Functional playground built over the jsr engine

`site/index.html` is now a working single-file playground (no build):
- imports `genv` from esm.sh (`jsr:@kindkitchen/genv@0.1.0`).
- in-site `steps_for` mirrors parity's from_action: 5 action steps -> ordered
  engine sources (content_from_vars, vars kv, content_from_secrets, secrets kv,
  dotenv_content literal).
- inputs: vars_obj / secrets_obj / dotenv_content + 6 regex patterns, prefilled
  with an illustrative default; live recompute on input; per-field JSON error.
- output: resolved `.env` + a per-step "merge timeline" (each step's contribution
  via `genv([source])`; inactive steps shown skipped) + copy button.
- also a brief landing (key points) and a hand-written 5-step docs section; the
  `GENERATED:action-inputs` marker is kept for the docs generator.
- Build-A-Map-leaning theme (warm palette, card board, parchment output) as a
  foundation, not the final art.

Verified: adapter + engine output validated end-to-end against the real published
engine via esm.sh (sample inputs -> correct resolved env and per-step lines). The
DOM wiring itself is not yet exercised in a live browser.
