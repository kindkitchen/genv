# Docs "Full spec" generator added (Deno)

`site/gen-docs.ts` reads action.yml inputs (`@std/yaml`) and injects an HTML table
into the `GENERATED:action-inputs` marker in index.html, so the option reference
can't drift from the action. Ran it: 10 inputs; table styling added.

Supersedes the earlier bash+jq/yq preference ([[003.decision]]): the project
standardized on Deno (engine, parity), so the generator is Deno too — consistent,
zero node_modules. It is a dev tool, not part of the deployed artifact
(site-gh-pages-deploy should publish index.html, not `*.ts`).

Run: `deno run --allow-read --allow-write site/gen-docs.ts`.
