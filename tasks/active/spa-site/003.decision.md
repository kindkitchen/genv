# Stack = static HTML; comments = GitHub-backed; docs = manual + generated spec

## Stack: single static HTML file
`site/index.html`, vanilla JS + inline CSS, no build step, no node_modules.
Matches the action's thin/zero-dependency ethos and is trivial on Pages. Merge
pipeline ported to client-side JS per [[002.analysis]].

## Comments: GitHub-backed footer
giscus (GitHub Discussions, the utterances successor) is the recommended choice;
utterances (Issues) is the fallback if issues-backed is preferred. Needs the app
installed + Discussions enabled on kindkitchen/genv. Wiring (repo id, category,
theme) deferred — a `<script>` embed, left as a footer placeholder.

## Docs sync: manual prose + generated full-spec
Hand-written documentation section kept as untouched as possible (README is
source of truth — mirror, don't duplicate logic). PLUS a generated "Full spec"
section from `action.yml` inputs so the exhaustive option reference can't drift.
Prefer a thin bash+jq/yq generator over a node build (ethos). Injection marker in
the scaffold: `GENERATED:action-inputs:{start,end}`.
