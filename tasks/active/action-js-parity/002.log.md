# Reframed by the js-engine pivot: this task now owns the GitHub adapter

js-engine [[js-engine/005.decision]] made the engine source-agnostic and dropped
bash-byte parity as an engine goal. Consequences here:

- The old framing "prove bash action == genv()" no longer holds: genv() no longer
  mirrors action.yml's 5-step pipeline.
- This task now owns the adapter that maps the action's GitHub inputs (vars_obj,
  secrets_obj, *_include/_exclude, content_from_*) onto the engine's agnostic
  source/fragment model.
- Parity becomes: raw bash action == adapter(engine merge) over the fixture
  corpus, not == bare engine. The corpus and thin/fast CI wiring still stand.
