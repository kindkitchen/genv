# Runtime/packaging: Deno + JSR TypeScript library

genv-js is a standard TypeScript library published at `jsr:@kindkitchen/genv`.
- Deno runtime; tests via `Deno.test` (no node_modules, no extra tooling).
- `import.meta.main` fallback so the module doubles as a runnable main file.
- SPA integration deferred to spa-site (expected trivial — import the JSR lib).

Layout: root `deno.json` (name/version/exports/tasks, `@std/assert` import map);
engine in `engine/`: `genv.ts` (impl + types), `mod.ts` (public re-export + CLI),
`genv.test.ts`. The CLI reads an inputs JSON from stdin and writes the dotenv to
stdout — the shape the action-js-parity harness will feed both sides.
