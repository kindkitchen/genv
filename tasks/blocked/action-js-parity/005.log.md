# Parity now consumes jsr:@kindkitchen/genv (off the submodule)

With the engine published ([[js-engine/009.log]]), switched `parity/` to import
`jsr:@kindkitchen/genv@^0.1.0` instead of `../engine/mod.ts`. `assert_equals`
(from the engine's unpublished `assert.ts`, excluded from the package) replaced by
`@std/assert`'s `assertEquals` — a dev-only parent dep. Still 8/8 green, lint/fmt
clean.

Effect: parity no longer depends on the (unpushed) submodule, so CI can run it
with only network access to JSR — no recursive submodule checkout of an unpushed
commit. This unblocks the pending CI wiring.
