      Why genv

      • Minimal coupling — update vars/secrets (keys, not just values) and rerun; no new commit to your yaml.
      • Flexible declaration — include/exclude patterns, value-vs-content, and merge order let you shape the file.
      • Last-win merge — ordered sources resolve conflicts predictably.

      Documentation

      The action runs five ordered steps, each appending to the file:

      1. content_from_vars_include_pattern — matching vars' values are inlined as raw content.
      2. vars_include_pattern / vars_exclude_pattern — remaining vars become KEY=value.
      3. content_from_secrets_include_pattern — matching secrets' values inlined as content.
      4. secrets_include_pattern / secrets_exclude_pattern — remaining secrets become KEY=value.
      5. dotenv_content — literal block, appended last (absolute priority).
